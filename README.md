# Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing customer shopping behavior across **3,900 transactions**.

The project uses **Python and Pandas** for data cleaning and feature engineering, **PostgreSQL** for SQL-based business analysis, and **Power BI** for interactive data visualization.

The objective is to identify meaningful patterns in customer spending, product preferences, subscription behavior, customer segments, and purchasing habits, and translate those findings into actionable business recommendations.

---

## Project Overview

This project follows a complete analytics workflow:

1. Load and explore the raw dataset using Python.
2. Clean missing and inconsistent data.
3. Standardize column names.
4. Engineer additional analytical features.
5. Load the cleaned dataset into PostgreSQL.
6. Analyze customer behavior using SQL.
7. Build an interactive Power BI dashboard.
8. Develop business recommendations from the findings.
9. Present the results through a project report and presentation.

---

## Missing Data Treatment

The dataset contained **37 missing values** in the `review_rating` column.

These values were imputed using the **median review rating within each product category**.

This approach preserved category-level differences rather than replacing every missing value with one global value.

---

## Column Standardization

Column names were converted into `snake_case` to improve readability and consistency.

Examples:

```text
Purchase Amount (USD) → purchase_amount
Review Rating → review_rating
Subscription Status → subscription_status
Previous Purchases → previous_purchases
```

---

## Feature Engineering

Two additional analytical features were created.

### Age Group

Customers were grouped into age-based segments using a new:

```text
age_group
```

column.

### Purchase Frequency

Purchase frequency categories were converted into numerical values using:

```text
purchase_frequency_days
```

This made purchase-frequency information easier to analyze quantitatively.

---

## Redundancy Check

The columns:

```text
discount_applied
promo_code_used
```

were compared and found to contain redundant information.

As a result:

```text
promo_code_used
```

was removed from the cleaned dataset.

Develop stronger subscriber incentives and exclusive benefits to encourage non-subscribers to join the subscription program.

Because non-subscribers represent the majority of the customer base, converting even a portion of this group could increase recurring customer engagement.

Provide incentives and rewards for repeat customers.

- Retain existing customers
- Increase repeat purchases
- Strengthen customer relationships
